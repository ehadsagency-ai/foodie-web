Cinq prototypes autres composants pour les rôles.

Cinq alternatives à la grille 4 cards déjà utilisée sur la home et aux 4 pages dédiées. Chaque prototype présente Customer, Producteur, Fondateur et Chef avec des composants différents.

Composants déjà utilisés (à éviter ici) : grille 4 cards rôle, role-features grid, role-numbers stats grid, role-faq dl/dt/dd, hero asymétrique 2 colonnes, marquee saison, OrbitingCircles écosystème, role-cta-band, cross-links 3 boutons.
Composants nouveaux introduits : tab-nav scroll-spy, comparison table sticky-header, bento grid asymétrique, quiz-stepper progress-bar, magazine masthead + drop-cap + pull-quote + multi-column + sidebar.
Prototype A

Sticky Tabs — One-Pager

Une seule page, quatre sections plein-écran, navigation par onglets sticky avec scroll-spy actif.

Composants nouveaux :

  • Tab-nav sticky horizontale avec border-bottom 3 px primary sur tab active
  • Scroll-spy via IntersectionObserver natif (sans lib)
  • Sections one-pager 80vh chacune avec scroll-margin-top
  • Stats inline definition-list (au lieu de grid cards)
  • Quotes border-left or au lieu de cards

Prototype B

Tableau comparatif dense

Quatre rôles, dix-huit critères, une seule table. Sticky header noir, lignes zébrées, hover ambre.

Composants nouveaux :

  • Comparison-table 4 colonnes × 18 lignes
  • Sticky thead position:sticky avec ombre
  • Section-row regroupements (Identité, Économie, Conformité, Plateforme)
  • Légende dot colorée (yes / lim / v2 / no) au-dessus de la table
  • tfoot avec CTAs alignés colonne par colonne

Prototype C

Bento Grid Apple-style

Prototype D

Quiz d'orientation interactif

Quatre questions guidées, un rôle suggéré. Stepper avec progress bar segmentée.

Composants nouveaux :

  • Progress bar segmentée 4 segments (line / current / done)
  • Choice-card radio fancy (dot animé + hover ambre + selected primary)
  • Stepper logic JS sans dépendance (4 questions → résultat)
  • Result-screen avec icon-big + badge + promise + cta
  • Logique d'orientation : intention (Q1) × disqualifications (Q2-Q4) → rôle

Prototype E

Magazine Longread

Format Le Monde Diplomatique. Masthead, drop-cap, pull-quotes, multi-colonnes, sidebar flottante, dividers étoile.

Composants nouveaux :

  • Masthead magazine (ribbon + title display + meta byline)
  • Drop-cap première lettre 5,5 rem rouge + first-line uppercase Inter
  • Pull-quotes magazine 2 rem italique avec cite
  • Multi-column 2 colonnes avec column-rule 1 px (CSS columns natif)
  • Sidebar flottante float:right avec dl/dt/dd encadré
  • Chapter headings numérotés (Acte premier, deuxième, troisième, quatrième)
  • Dividers étoile entre sections
  • Final-CTA noir+or au format encadré bordure 3 px double
